** Overview

This phase sets up automated backups:
- Backup script for critical data
- Automated daily backups via cron
- Backup rotation (keep N days)
- Easy restore procedure

** Backup Script

#+begin_src bash :tangle ../configs/templates/backup.sh.j2
#!/bin/bash
# Automated backup script
# Backs up critical configuration files to {{ backup_dir }}
# This is a selective backup - only essential configs, NOT entire /etc
# Backups contain private keys, so they are age-encrypted to the recipient
# key; the script refuses to write a plaintext archive.

set -euo pipefail

BACKUP_DIR="{{ backup_dir }}"
AGE_RECIPIENT_FILE="{{ backup_age_recipient }}"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
BACKUP_NAME="backup_${TIMESTAMP}"
BACKUP_PATH="${BACKUP_DIR}/${BACKUP_NAME}"
RETENTION_DAYS={{ backup_retention_days }}

# Never back up secrets in plaintext - require the encryption key
if [ ! -s "$AGE_RECIPIENT_FILE" ]; then
  echo "ERROR: age recipient file missing: $AGE_RECIPIENT_FILE" >&2
  echo "Backups contain private keys and must be encrypted." >&2
  echo "Re-run the backup phase of the playbook to generate the key." >&2
  exit 1
fi

# Ensure backup directory exists
mkdir -p "$BACKUP_DIR"

echo "=== Starting backup at $(date) ==="
echo "Backup destination: $BACKUP_PATH"

# Create backup directory
mkdir -p "$BACKUP_PATH"

# Function to backup a path
backup_path() {
  local src="$1"
  local dest="$2"

  if [ -e "$src" ]; then
    echo "Backing up: $src"
    mkdir -p "$(dirname "$dest")"
    rsync -a "$src" "$dest/"
  else
    echo "Skipping (not found): $src"
  fi
}

# System Configuration (selective, not all of /etc)
echo "--- System Configuration ---"
backup_path "/etc/wireguard" "$BACKUP_PATH/etc"
backup_path "/etc/ssh/sshd_config" "$BACKUP_PATH/etc/ssh"
backup_path "/etc/tor/torrc" "$BACKUP_PATH/etc/tor"
backup_path "/etc/i2pd/tunnels.d" "$BACKUP_PATH/etc/i2pd"
backup_path "/etc/monerod.conf" "$BACKUP_PATH/etc"

# User Data
echo "--- User Data ---"
backup_path "/home/{{ dev_user }}/.secrets" "$BACKUP_PATH/home/{{ dev_user }}"
backup_path "/home/{{ dev_user }}/.gitconfig" "$BACKUP_PATH/home/{{ dev_user }}"
backup_path "/home/{{ dev_user }}/Documents" "$BACKUP_PATH/home/{{ dev_user }}"

# Mining Configuration
echo "--- Mining Configuration ---"
mkdir -p "$BACKUP_PATH/mining"
backup_path "/opt/xmrig/build/config.json" "$BACKUP_PATH/mining"

# Haveno (RetoSwap) trade wallet + data dir.
# Holds the trade wallet, Tor onion key, and trade history. backup_path
# skips cleanly when the exchange phase is not installed (path absent).
echo "--- Haveno Exchange ---"
backup_path "{{ haveno_data_dir }}" "$BACKUP_PATH/haveno"

# Interop: cast encrypted keystore (no-HW-wallet fallback only). Absent when
# signing is hardware-backed (the preferred path) — backup_path skips cleanly.
# A hardware wallet's seed is NEVER on the box; back it up out-of-band.
echo "--- Interop (cast keystore) ---"
backup_path "{{ foundry_keystore_dir }}" "$BACKUP_PATH/cast"

# Interop: Rabby wallet Chromium profile (dapp-UI fallback). Holds the
# extension's settings and, if not paired with a hardware wallet, the encrypted
# hot key. backup_path skips cleanly when the Rabby fallback is not installed.
# Paired with a hardware wallet, the seed is on the device (backed up out-of-band)
# and the profile is re-derivable — so this is a convenience backup, not custody.
echo "--- Interop (Rabby wallet profile) ---"
backup_path "/home/{{ dev_user }}/.config/chromium/{{ rabby_profile }}" "$BACKUP_PATH/rabby"

# Create backup manifest
echo "--- Creating Manifest ---"
cat > "$BACKUP_PATH/manifest.txt" << EOF
Backup created: $(date)
Hostname: {{ system_hostname }}
Backup name: $BACKUP_NAME
Encryption: age (recipient from $AGE_RECIPIENT_FILE; decrypt with the offline identity)

Contents:
$(find "$BACKUP_PATH" -type f | wc -l) files
$(du -sh "$BACKUP_PATH" | cut -f1) total size

Critical configs backed up:
- WireGuard: /etc/wireguard (peers, keys)
- SSH: /etc/ssh/sshd_config
- Tor: /etc/tor/torrc
- I2P: /etc/i2pd/tunnels.d
- Monerod: /etc/monerod.conf
- Secrets: /home/{{ dev_user }}/.secrets (SSH keys, GPG keys, wallets)
- Git config: /home/{{ dev_user }}/.gitconfig
- KeePassXC databases: /home/{{ dev_user }}/Documents/*.kdbx (encrypted blobs)
- XMRig config: /opt/xmrig/build/config.json
- Haveno trade wallet: {{ haveno_data_dir }} (trade wallet, Tor onion key) [if installed]
- cast keystore: {{ foundry_keystore_dir }} (encrypted; no-HW fallback only) [if present]
- Rabby wallet profile: ~/.config/chromium/{{ rabby_profile }} (dapp-UI fallback) [if present]

NOT backed up (Ansible regenerates):
- Systemd service files
- Other /etc templates
- XMRig/P2Pool binaries
- Monerod blockchain (backup separately)
EOF

# Compress and encrypt backup
echo "--- Compressing and Encrypting Backup ---"
cd "$BACKUP_DIR"
if tar czf - "$BACKUP_NAME" | age -R "$AGE_RECIPIENT_FILE" > "${BACKUP_NAME}.tar.gz.age"; then
  rm -rf "$BACKUP_NAME"
  chmod 600 "${BACKUP_NAME}.tar.gz.age"
  echo "Backup encrypted: ${BACKUP_NAME}.tar.gz.age"
  echo "Size: $(du -h "${BACKUP_NAME}.tar.gz.age" | cut -f1)"

  # Remove old backups only after successful new backup
  echo "--- Cleaning Old Backups ---"
  find "$BACKUP_DIR" -name "backup_*.tar.gz.age" -mtime +$RETENTION_DAYS -delete
  echo "Removed backups older than $RETENTION_DAYS days"

  # Legacy plaintext backups predate encryption - rotate them out too
  LEGACY=$(find "$BACKUP_DIR" -maxdepth 1 -name "backup_*.tar.gz" -type f)
  if [ -n "$LEGACY" ]; then
    echo "WARNING: plaintext legacy backups present (contain unencrypted keys):"
    echo "$LEGACY"
    echo "Delete them once you have verified an encrypted backup restores."
  fi
else
  echo "ERROR: Backup encryption failed!"
  rm -rf "$BACKUP_NAME" "${BACKUP_NAME}.tar.gz.age"
  exit 1
fi

# List remaining backups
echo "--- Current Backups ---"
ls -lh "$BACKUP_DIR"/backup_*.tar.gz.age 2>/dev/null || echo "No backups found"

echo "=== Backup completed at $(date) ==="

# Log to journal
logger -t backup "Backup completed: ${BACKUP_NAME}.tar.gz.age"

exit 0
#+end_src

** Restore Script

#+begin_src bash :tangle ../configs/templates/restore.sh.j2
#!/bin/bash
# Restore from backup
# Usage: restore.sh <backup-file.tar.gz.age> [path]
# Encrypted backups (.tar.gz.age) are decrypted with the age identity;
# set AGE_IDENTITY_FILE to override the default location.

set -euo pipefail

AGE_IDENTITY_FILE="${AGE_IDENTITY_FILE:-{{ backup_age_identity }}}"

if [ $# -lt 1 ]; then
  echo "Usage: $0 <backup-file.tar.gz.age> [specific-path]"
  echo ""
  echo "Available backups:"
  ls -lh {{ backup_dir }}/backup_*.tar.gz.age 2>/dev/null || echo "  No backups found"
  echo ""
  echo "Examples:"
  echo "  $0 {{ backup_dir }}/backup_20250101_120000.tar.gz.age           # Show contents"
  echo "  $0 {{ backup_dir }}/backup_20250101_120000.tar.gz.age etc       # Restore all configs"
  echo "  $0 {{ backup_dir }}/backup_20250101_120000.tar.gz.age home      # Restore user data"
  echo "  $0 {{ backup_dir }}/backup_20250101_120000.tar.gz.age mining    # Restore mining config"
  echo "  $0 {{ backup_dir }}/backup_20250101_120000.tar.gz.age haveno    # Restore Haveno trade wallet"
  echo "  $0 {{ backup_dir }}/backup_20250101_120000.tar.gz.age cast      # Restore cast keystore"
  echo "  $0 {{ backup_dir }}/backup_20250101_120000.tar.gz.age rabby     # Restore Rabby wallet profile"
  exit 1
fi

BACKUP_FILE="$1"
RESTORE_PATH="${2:-}"
RESTORE_DIR="{{ backup_dir }}/restore_$(date +%Y%m%d_%H%M%S)"

if [ ! -f "$BACKUP_FILE" ]; then
  echo "Error: Backup file not found: $BACKUP_FILE"
  exit 1
fi

echo "=== Starting restore at $(date) ==="
echo "Backup file: $BACKUP_FILE"
echo "Restore location: $RESTORE_DIR"

# Reject archive members that would escape the extraction directory.
# The archive is data at rest that may have been tampered with - never
# trust member paths.
check_tar_members() {
  local bad
  bad=$(tar tzf "$1" | grep -E '^/|(^|/)\.\.(/|$)' || true)
  if [ -n "$bad" ]; then
    echo "Error: archive contains unsafe paths:" >&2
    echo "$bad" | head -5 >&2
    exit 1
  fi
}

# Extract backup
echo "--- Extracting Backup ---"
mkdir -p "$RESTORE_DIR"
TARBALL="$RESTORE_DIR/.backup.tar.gz"
case "$BACKUP_FILE" in
  *.tar.gz.age)
    if [ ! -s "$AGE_IDENTITY_FILE" ]; then
      echo "Error: age identity not found: $AGE_IDENTITY_FILE"
      echo "Restore your offline identity copy to that path, or point"
      echo "AGE_IDENTITY_FILE at it."
      exit 1
    fi
    age -d -i "$AGE_IDENTITY_FILE" "$BACKUP_FILE" > "$TARBALL"
    ;;
  *.tar.gz)
    echo "WARNING: restoring a legacy plaintext backup"
    cp "$BACKUP_FILE" "$TARBALL"
    ;;
  *)
    echo "Error: unrecognized backup format: $BACKUP_FILE"
    exit 1
    ;;
esac

check_tar_members "$TARBALL"
tar xzf "$TARBALL" -C "$RESTORE_DIR"
rm -f "$TARBALL"

# Find the extracted directory
EXTRACTED_DIR=$(find "$RESTORE_DIR" -maxdepth 1 -type d -name "backup_*" | head -n 1)

if [ -z "$EXTRACTED_DIR" ]; then
  echo "Error: Could not find extracted backup directory"
  exit 1
fi

# Show manifest
echo "--- Backup Manifest ---"
cat "$EXTRACTED_DIR/manifest.txt"
echo ""

# Restore specific path or show contents
if [ -n "$RESTORE_PATH" ]; then
  echo "--- Restoring: $RESTORE_PATH ---"

  if [ -d "$EXTRACTED_DIR/$RESTORE_PATH" ]; then
    # Restore to system
    case "$RESTORE_PATH" in
      etc)
        echo "Restoring system configs..."
        rsync -av "$EXTRACTED_DIR/etc/" /etc/
        echo "✓ Restored configs to /etc"
        echo "  Restart affected services:"
        echo "    sudo systemctl restart wg-quick@wg0 tor i2pd monerod"
        ;;
      home)
        echo "Restoring user data..."

        # Restore .secrets first
        if [ -d "$EXTRACTED_DIR/home/{{ dev_user }}/.secrets" ]; then
          echo "  Restoring secrets..."
          rsync -av "$EXTRACTED_DIR/home/{{ dev_user }}/.secrets/" "/home/{{ dev_user }}/.secrets/"
          chown -R {{ dev_user }}:{{ dev_user }} "/home/{{ dev_user }}/.secrets"
          chmod 700 "/home/{{ dev_user }}/.secrets"

          # Create symlinks (only if they don't exist)
          echo "  Creating symlinks..."

          if [ ! -L "/home/{{ dev_user }}/.ssh" ]; then
            [ -e "/home/{{ dev_user }}/.ssh" ] && echo "  WARNING: ~/.ssh exists but is not a symlink"
            ln -s "/home/{{ dev_user }}/.secrets/ssh" "/home/{{ dev_user }}/.ssh"
          fi

          if [ ! -L "/home/{{ dev_user }}/.gnupg" ]; then
            [ -e "/home/{{ dev_user }}/.gnupg" ] && echo "  WARNING: ~/.gnupg exists but is not a symlink"
            ln -s "/home/{{ dev_user }}/.secrets/gnupg" "/home/{{ dev_user }}/.gnupg"
          fi

          if [ ! -L "/home/{{ dev_user }}/.bitmonero" ]; then
            [ -e "/home/{{ dev_user }}/.bitmonero" ] && echo "  WARNING: ~/.bitmonero exists but is not a symlink"
            ln -s "/home/{{ dev_user }}/.secrets/wallets/bitmonero" "/home/{{ dev_user }}/.bitmonero"
          fi

          mkdir -p "/home/{{ dev_user }}/Monero"
          if [ ! -L "/home/{{ dev_user }}/Monero/wallets" ]; then
            [ -e "/home/{{ dev_user }}/Monero/wallets" ] && echo "  WARNING: ~/Monero/wallets exists but is not a symlink"
            ln -s "/home/{{ dev_user }}/.secrets/wallets/feather" "/home/{{ dev_user }}/Monero/wallets"
          fi

          echo "✓ Restored secrets and created symlinks"
        fi

        # Restore other user data (Documents, .gitconfig, etc.)
        rsync -av --exclude='.secrets' "$EXTRACTED_DIR/home/{{ dev_user }}/" "/home/{{ dev_user }}/"
        chown -R {{ dev_user }}:{{ dev_user }} "/home/{{ dev_user }}/.gitconfig" "/home/{{ dev_user }}/Documents"
        echo "✓ Restored user data to /home/{{ dev_user }}"
        ;;
      mining)
        echo "Restoring mining config..."
        rsync -av "$EXTRACTED_DIR/mining/" /opt/xmrig/build/
        echo "✓ Restored mining config"
        echo "  Restart mining:"
        echo "    sudo systemctl restart xmrig"
        ;;
      haveno)
        echo "Restoring Haveno trade wallet..."
        mkdir -p "/home/{{ dev_user }}/.local/share"
        # The archive stores it as haveno/Haveno-reto/...; restore into
        # .local/share so the data dir name is preserved regardless of config.
        rsync -av "$EXTRACTED_DIR/haveno/" "/home/{{ dev_user }}/.local/share/"
        chown -R {{ dev_user }}:{{ dev_user }} "{{ haveno_data_dir }}"
        chmod 700 "{{ haveno_data_dir }}"
        echo "✓ Restored Haveno data dir"
        echo "  Launch when ready (no service): haveno-sandboxed"
        ;;
      cast)
        echo "Restoring cast keystore..."
        install -d -o {{ dev_user }} -g {{ dev_user }} -m 700 \
          "/home/{{ dev_user }}/.foundry"
        rsync -av "$EXTRACTED_DIR/cast/" "{{ foundry_keystore_dir }}/"
        chown -R {{ dev_user }}:{{ dev_user }} "{{ foundry_keystore_dir }}"
        chmod -R go-rwx "{{ foundry_keystore_dir }}"
        echo "✓ Restored cast keystore"
        echo "  Use: cast-tor ... --account <name> --password-file ..."
        ;;
      rabby)
        echo "Restoring Rabby wallet profile..."
        install -d -o {{ dev_user }} -g {{ dev_user }} -m 700 \
          "/home/{{ dev_user }}/.config/chromium/{{ rabby_profile }}"
        rsync -av "$EXTRACTED_DIR/rabby/" \
          "/home/{{ dev_user }}/.config/chromium/{{ rabby_profile }}/"
        chown -R {{ dev_user }}:{{ dev_user }} \
          "/home/{{ dev_user }}/.config/chromium/{{ rabby_profile }}"
        echo "✓ Restored Rabby wallet profile"
        echo "  Launch when ready (no service): rabby-wallet"
        ;;
      *)
        # Whitelist only - a free-form path here would let a tampered
        # backup (or a typo) overwrite arbitrary system directories.
        echo "Error: unknown restore path: $RESTORE_PATH (valid: etc, home, mining, haveno, cast, rabby)"
        exit 1
        ;;
    esac
  else
    echo "Error: Path not found in backup: $RESTORE_PATH"
    echo "Available paths:"
    ls -la "$EXTRACTED_DIR/"
    exit 1
  fi
else
  echo "--- Backup Contents ---"
  tree -L 3 "$EXTRACTED_DIR" 2>/dev/null || find "$EXTRACTED_DIR" -maxdepth 3 -type d
  echo ""
  echo "To restore specific components:"
  echo "  $0 $BACKUP_FILE etc       # System configs (WireGuard, SSH, Tor, I2P, monerod)"
  echo "  $0 $BACKUP_FILE home      # User data (SSH keys, GPG, git config)"
  echo "  $0 $BACKUP_FILE mining    # Mining config"
  echo "  $0 $BACKUP_FILE haveno    # Haveno trade wallet (if backed up)"
  echo ""
  echo "Extracted files available at:"
  echo "  $EXTRACTED_DIR"
  echo ""
  echo "To restore everything:"
  echo "  $0 $BACKUP_FILE etc && $0 $BACKUP_FILE home && $0 $BACKUP_FILE mining"
fi

echo "=== Restore completed at $(date) ==="

# Log to journal
logger -t restore "Restore completed from: $BACKUP_FILE ($RESTORE_PATH)"

exit 0
#+end_src

** Backup Verification Script

#+begin_src bash :tangle ../configs/templates/verify-backup.sh.j2
#!/bin/bash
# Verify backup integrity
# Decrypts each archive with the age identity and checks the tar stream.

BACKUP_DIR="{{ backup_dir }}"
AGE_IDENTITY_FILE="${AGE_IDENTITY_FILE:-{{ backup_age_identity }}}"

echo "=== Backup Verification ==="

if [ ! -d "$BACKUP_DIR" ]; then
  echo "Error: Backup directory not found: $BACKUP_DIR"
  exit 1
fi

# List all backups
echo "--- Available Backups ---"
BACKUPS=$(find "$BACKUP_DIR" -name "backup_*.tar.gz.age" -type f | sort)

if [ -z "$BACKUPS" ]; then
  echo "No backups found in $BACKUP_DIR"
  exit 1
fi

echo "$BACKUPS"
echo ""

# Warn about plaintext leftovers from before encryption was introduced
LEGACY=$(find "$BACKUP_DIR" -maxdepth 1 -name "backup_*.tar.gz" -type f)
if [ -n "$LEGACY" ]; then
  echo "WARNING: plaintext legacy backups present (contain unencrypted keys):"
  echo "$LEGACY"
  echo ""
fi

# Test each backup
echo "--- Testing Backup Integrity ---"
for backup in $BACKUPS; do
  echo -n "Testing: $(basename $backup)... "
  if [ -s "$AGE_IDENTITY_FILE" ]; then
    if age -d -i "$AGE_IDENTITY_FILE" "$backup" 2>/dev/null | tar tz > /dev/null 2>&1; then
      size=$(du -h "$backup" | cut -f1)
      echo "OK (size: $size)"
    else
      echo "FAILED"
    fi
  else
    # Without the identity we can only check the age header
    if head -c 21 "$backup" | grep -q "age-encryption.org/v1"; then
      size=$(du -h "$backup" | cut -f1)
      echo "OK header, not decrypted - identity unavailable (size: $size)"
    else
      echo "FAILED (not an age file)"
    fi
  fi
done

echo ""
echo "--- Backup Statistics ---"
echo "Total backups: $(echo "$BACKUPS" | wc -l)"
echo "Total size: $(du -sh $BACKUP_DIR | cut -f1)"
echo "Oldest: $(basename $(echo "$BACKUPS" | head -n 1))"
echo "Newest: $(basename $(echo "$BACKUPS" | tail -n 1))"

exit 0
#+end_src

** Backup Encryption Key

Backups contain private keys (SSH, GPG, wallets, WireGuard), so they are
encrypted with [[https://age-encryption.org][age]]. The recipient (public key)
encrypts automated backups; the identity (private key) is only needed to
restore. Both live under =/etc/backup= — outside =backup_dir= and outside the
set of paths the backup script copies, so a backup never contains its own
decryption key.

*Copy the identity somewhere offline* (KeePassXC entry, paper). If the disk
dies, the on-disk identity dies with it and the offsite backup copies are
unrecoverable without your offline copy.

#+begin_src yaml :tangle ../ansible/fragments/83-backup.yml
    # ------------------------------------------------------------------------
    # Backup & Recovery
    # ------------------------------------------------------------------------

    - name: Install age encryption tool
      community.general.pacman:
        name: age
        state: present
      tags: [backup]

    - name: Create backup key directory
      file:
        path: /etc/backup
        state: directory
        owner: root
        group: root
        mode: '0700'
      tags: [backup]

    - name: Generate backup age identity (once)
      command: age-keygen -o {{ backup_age_identity }}
      args:
        creates: "{{ backup_age_identity }}"
      tags: [backup]

    - name: Restrict identity permissions
      file:
        path: "{{ backup_age_identity }}"
        owner: root
        group: root
        mode: '0600'
      tags: [backup]

    - name: Derive age recipient from identity
      shell: age-keygen -y {{ backup_age_identity }} > {{ backup_age_recipient }}
      args:
        creates: "{{ backup_age_recipient }}"
      tags: [backup]

    - name: Remind operator to store identity offline
      debug:
        msg:
          - "BACKUP ENCRYPTION: identity at {{ backup_age_identity }}"
          - "Copy it to offline storage (KeePassXC / paper) NOW."
          - "Without it, backups cannot be restored after disk loss."
      tags: [backup]
#+end_src

*** What Gets Backed Up

**Critical configuration files (selective, not entire /etc):**
- WireGuard: `/etc/wireguard` (peers, keys)
- SSH: `/etc/ssh/sshd_config`
- Tor: `/etc/tor/torrc`
- I2P: `/etc/i2pd/tunnels.d`
- Monerod: `/etc/monerod.conf`

**User data:**
- SSH keys: `/home/dev/.ssh` (both server access and git hosting keys)
- GPG keys: `/home/dev/.gnupg`
- Git config: `/home/dev/.gitconfig`

**Encrypted data (safe to backup):**
- KeePassXC databases: `~/Documents/*.kdbx` (encrypted with master password)
- Monero wallets: `~/Monero/wallets/` (encrypted with wallet password)
- Feather config: `~/.config/feather` (settings only, seed phrases should be in KeePassXC)

**Mining configuration:**
- XMRig config: `/opt/xmrig/build/config.json`

**Exchange (only if the exchange phase is enabled):**
- Haveno trade wallet + data dir: `~/.local/share/Haveno-reto` (trade wallet,
  Tor onion identity, trade history). Skipped cleanly when not installed.
  These are hot funds — back them up, but keep balances minimal.

**What is NOT backed up:**
- Systemd services (Ansible regenerates these)
- XMRig/P2Pool binaries (rebuilt/re-downloaded)
- Monerod blockchain (~250GB - too large, re-syncs on restore)
- Temporary files (*.tmp, *.log, *.cache)

**Backup philosophy:** Store only what cannot be regenerated. Ansible playbooks recreate system services and install software. Backups preserve unique configuration and keys.

*** Backup Safety

The backup process now:
1. Creates backup in temporary directory
2. Compresses backup
3. Verifies compression succeeded
4. Only then deletes old backups

This prevents data loss if backup fails partway through.

*** Backup to External Drive

#+begin_example
# Mount external drive
sudo mount /dev/sdX1 /mnt/backup

# Copy backups
sudo cp {{ backup_dir }}/backup_*.tar.gz.age /mnt/backup/

# Or rsync
sudo rsync -av {{ backup_dir }}/ /mnt/backup/

# Unmount
sudo umount /mnt/backup
#+end_example

*** Disaster Recovery

If you need to rebuild from scratch:

1. Fresh Omarchy install
2. Clone this repo
3. Run bootstrap
4. Restore your offline age identity to ={{ backup_age_identity }}=
   (mode 0600, owner root)
5. Copy backup to {{ backup_dir }}
6. Run restore: =sudo restore.sh <backup-file.tar.gz.age>=
7. Re-run Ansible: =ansible-playbook playbook.yml=

*** Backup Size

Expected backup sizes:
- Mining config: < 10 MB
- System config: < 50 MB
- User data (SSH keys, GPG): < 10 MB

Total: ~70 MB per backup (compressed)

*** Backup Security

Backups are age-encrypted to the recipient key in
={{ backup_age_recipient }}=; =backup.sh= refuses to run if the recipient is
missing, so plaintext archives of key material are never written. Decryption
requires the identity at ={{ backup_age_identity }}= (root-only, 0600).

Key handling:
1. The identity is generated once by the backup phase and never leaves
   =/etc/backup= — it is deliberately excluded from the backup contents.
2. Copy the identity offline (KeePassXC entry or paper). This is the only
   way to restore after disk loss.
3. Encrypted =.tar.gz.age= files are safe to copy to external drives or
   cloud storage; the identity is what must stay private.

Layering LUKS or an encrypted external drive on top still helps (it also
protects filenames and timing), but is no longer the only barrier.
